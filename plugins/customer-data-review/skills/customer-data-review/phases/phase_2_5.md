# Phase 2.5: One sampled audit and at most one correction

The locked request records `audit_mode`: `sampled` by default; `skip` only by explicit user choice before initialization. Never regenerate the sample or widen it to improve its score. No new audit rounds.

1. `RUN bounded_audit prepare --root . --mode sampled` locks the deterministic sample of up to20 mentions from at most6 sources and its content fingerprints. Use `--mode skip` only when it matches the request. Source caps can leave question/source-type cells uncovered; report that limitation. Skip mode runs no semantic tasks and proceeds to finalization with a null semantic agreement rate.
2. Read `prompts/audit_mention.md` once. In sampled mode, `RUN batch_extract audit-read --root . --size 4 --output synthesis/batches/audit-input.json` reserves up to4 selected sources and supplies their complete texts and locked task mentions. Read the full saved file if displayed output truncates. Workers return one verdict per supplied mention, preserving `mention_id` and `fingerprint`, with `verdict` (`pass`, `fail`, `uncertain`) and a nonempty source-based `reason`.
3. Save `audit-batch.json` as an object mapping each `file_id` to its verdict array. `RUN batch_extract audit-save --root . --input audit-batch.json` validates and checkpoints each source. Finish the current healthy batch before reserving another. A malformed initial verdict batch may use its existing single `audit-read --retry`; preserve every already-valid initial decision, including failures. This structural retry is not a semantic correction.
4. Once all initial verdicts are saved, run `RUN batch_extract audit-assess --root .`. This reports the exact fixed-sample result and next action without sealing the audit. Do not use finalization to discover whether correction is needed. At or above90%, finalize with failed/uncertain items excluded; do not dispatch a correction to reach100%.
5. Below90%, use the one correction if the controller remains active. `RUN batch_extract audit-repair-read --root . --size 4 --output synthesis/batches/audit-repair-input.json` freezes the complete original failed cohort and reserves up to4 source-scoped tasks. Each worker reads its full source once, corrects/rechecks only the supplied failed mentions, and returns an array. A passing row contains the original `mention_id`/`fingerprint`, `verdict:"pass"`, a source-based `reason` and a full corrected mention in `replacement`; retain mention/question IDs. An unresolved row uses `fail` or `uncertain` with `replacement:null`. No new mentions, unrelated rejudgment or second semantic draft.
6. Save corrections as an object mapping each `file_id` to its correction array: `RUN batch_extract audit-repair-save --root . --input audit-repair-batch.json`. The parent helper supplies the missing replacement fingerprint deterministically, verifies exact source/ID/quote attribution constraints and freezes the submitted result. Do not hand-author `repairs.json` or compute hashes by inspecting Python. Repeat read/save only for undispatched sources in the original cohort. Once correction begins, finish that whole fixed cohort before finalization, even if one early result crosses90%. An identical save may recover interrupted deterministic saving; it never authorizes another model draft. Correction read/save has no `--retry`. Malformed or unusable correction means incomplete.
7. `RUN batch_extract audit-finalize --root .` assembles only accepted correction receipts, verifies the gate and seals the final artifacts. An accidental early call below90% cannot consume the correction opportunity. A completed correction that still misses90% seals incomplete and ends the run. To deliberately close an unrepairable or interrupted audit, use `RUN batch_extract audit-finalize --root . --allow-incomplete`; this is terminal, never a way to bypass the gate. A finalized audit cannot change its verdicts, repairs, sample or denominator.
8. A ready result proceeds to Phase3. Otherwise write `reports/incomplete.md` with the exact reason and stop. Raw extraction remains unchanged; corrections and exclusions are separate. Unselected mentions pass through without an audited label. Excluded items remain failures in the original sample denominator. Reports disclose sample/source coverage, uncovered cells, initial/final agreement, exclusions and unassessed count; sampled agreement is not whole-dataset accuracy.
